App name: SmartPantryManager

Description: Smart Pantry Manager is an Android Studio, Android application
that enables households to use what they already have which practices not
wasting ingredients. The user records each ingredient in the pantry with
a quantity, a unit and an expiry date. The app compares the pantry list of
ingredients against a built-in set of fifteen recipes and shows only the
recipes that can be cooked immediately, with no shopping trip required.

Use of SQLite: The application stores its data in a local SQLite database called smartpantry.db.
It works well with the development of Java code as its lightweight and does not need configuration before first use.
There are three tables. The pantry holds what the user owns, and the two recipe tables hold the reference data
that is seeded once when the database is first created.

Setup: Make sure Android studio is installed on the system as well as all additional files
before first load into the development of Android studio.

Next, open the downloaded SmartPantryManager and let the studio complete opening the folder.

Next, install an emulator via the Device Manager + icon.

Select Pixel 8 as it was used in the development and wait for the image to download to the
Android Studio environment in Device Manager.

Once installed, start the app by pressing on the green play button top of the Android Studio window
for a few minutes for the first boot of the emulator to start correctly. The app will open and be
sluggish for the first few minutes as the application loads for the first time.

The app should be running as intended during development. Happy cooking.
